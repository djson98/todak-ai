## 3️⃣ API 연동 확인

### 3-1. 백엔드 API 직접 테스트

```bash
# 서버 상태 확인
curl http://localhost:8000/health

# 일기 목록 조회 (테스트용)
curl http://localhost:8000/api/diary?user_id=test_user

# 일기 생성 테스트 (Firebase 설정 시)
curl -X POST http://localhost:8000/api/diary/ \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "test_user",
    "date": "2024-01-15T10:00:00",
    "content": "테스트 일기입니다.",
    "emotion": "JOY"
  }'
```

### 3-2. 프론트엔드에서 API 호출 확인

iOS 시뮬레이터에서:
1. 앱 실행 후 로그인 화면 표시 확인
2. 로그인 버튼 클릭
3. 홈 화면으로 이동
4. 일기 작성 버튼 클릭
5. 일기 작성 후 저장 시도

**확인 사항:**
- 네트워크 에러가 발생하는지 확인
- 백엔드 서버 터미널에서 API 요청 로그 확인
- Expo 개발자 도구에서 네트워크 요청 확인

## 5️⃣ 문제 해결

### 백엔드 서버가 응답하지 않는 경우

1. **포트 확인**
   ```bash
   lsof -i :8000
   ```

2. **프로세스 종료 후 재시작**
   ```bash
   lsof -ti :8000 | xargs kill -9
   # 서버 재시작
   ```

### 프론트엔드에서 연결 실패하는 경우

1. **API 주소 확인**
   - `mobile/services/api.ts` 파일에서 `API_BASE_URL` 확인
   - iOS 시뮬레이터: `http://localhost:8000` (맞음)

2. **백엔드 서버 실행 확인**
   ```bash
   curl http://localhost:8000/health
   ```

3. **Expo 개발 서버 재시작**
   ```bash
   cd mobile
   npm start
   # 'i' 키로 iOS 시뮬레이터 재실행
   ```

### Firebase 관련 에러

**현재 상태:**
- Firebase가 설정되지 않아 데이터 저장은 실패
- 하지만 API 구조 자체는 정상 작동

**해결 방법:**
1. `docs/firebase-setup.md` 참고하여 Firebase 설정
2. `.env` 파일에 `FIREBASE_CREDENTIALS_PATH` 설정
3. 서버 재시작
