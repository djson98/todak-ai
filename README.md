# todak-ai

## What is Todak?

Todak(토닥이)은 힘들 때 감정을 정리하기 어려운 순간에, 친구가 전화해서 "너 괜찮아?"라고 물어봐주듯 사용자에게 먼저 말을 걸어주는 AI 일기 앱입니다.

사용자는 일기나 짧은 기록을 남기기만 하면 되고, 토닥이는 그 기록을 바탕으로 감정을 정리할 수 있도록 도와줍니다.

## Why Todak?

힘든 날일수록 감정을 정리하려고 하면 더 어려워집니다. 머릿속이 복잡해지고, 같은 생각이 반복되며, 악순환에 빠지게 됩니다.

필요한 일은 "일기 써봐", "머리 속을 정리해봐" 같은 조언이 아니라, 먼저 다가와서 "괜찮아?"라고 안부를 묻는 것이라고 생각했습니다.

그래서 토닥이는 사용자가 필요할 때, 부담스럽지 않은 방식으로 먼저 말을 걸어줍니다.

## Core Features

### 1. 감정 기록

이모티콘 하나만으로도 간단하게 감정을 기록할 수 있고, 여유가 있을 때는 짧은 일기나 문장으로 더 자세히 남길 수 있습니다.

### 2. 감정 패턴 분석

기록이 쌓이면 패턴이 드러납니다. 언제 힘들었는지, 어떤 상황 이후에 힘들어졌는지, 반복되는 조건이 있는지를 알려줍니다.

### 3. 먼저 말을 걸어주는 기능

시험이 끝난 날과 같은 특정 이벤트가 발생했을 때, 사용자에게 먼저 말을 겁니다. "오늘 시험 보느라 많이 힘들지 않았어?"

## High-level Architecture

Todak은 다음 흐름으로 동작합니다.

1. 사용자가 이모티콘 또는 짧은 일기로 감정을 기록합니다.
2. 시스템이 기록을 저장하고, 시간에 따라 감정 변화와 패턴을 누적합니다.
3. 기록과 함께 캘린더의 일정 정보와 같은 맥락을 참고하여 현재 상태를 해석합니다.
4. 감정 정리 결과를 제공하고, 필요할 때 사용자에게 먼저 말을 겁니다.
